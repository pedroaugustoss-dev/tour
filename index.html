VanillaTour — Documentação

Tour puro: inicia apenas quando chamado (botão ?, start() ou bindTrigger). Sem auto-start nem sessão.

Navegação

Visão geral

O VanillaTour é um componente de tour guiado. Ele não inicia sozinho e não valida login — só executa quando você chama start(), bindTrigger() ou o usuário clica no botão ?.

Arquivos

  • Tour.js — engine
  • *-tour-config.js — configuração por página
  • novo-tour-config.js — template

Integração mínima

<!-- Template Django --> <script type="module"> import '../static/js/Tour/home-tour-config.js'; </script>

Com showHelpButton: true, o botão ? aparece ao carregar a página.

Passo a passo — criar um tour

Escolha o método de integração. Em ambos, o tour só inicia quando chamado — o botão ? aparece ao instanciar VanillaTour com showHelpButton: true.

Recomendado para telas novas. Separa a configuração do tour em *-tour-config.js e importa via <script type="module">.

1
Copie o template

Duplique novo-tour-config.js e renomeie para a sua tela.

minha-tela-tour-config.js
# Estrutura de arquivos PortalOficina/Oficina/static/js/Tour/ ├── Tour.js ├── novo-tour-config.js ← template └── minha-tela-tour-config.js ← seu arquivo
2
Marque os elementos no HTML

Use data-tour ou seletores CSS/ID que existam no DOM.

MinhaTela.html
<!-- Destaque no tour --> <div class="card" data-tour="painel-principal"> ... </div> <button id="btn-salvar">Salvar</button>
3
Configure o tour

Defina helpButtonId, settings e o array steps.

minha-tela-tour-config.js
import { VanillaTour, TourRegistry, createTourTrigger } from './Tour.js'; const config = { helpButtonId: 'v-help-btn-minha-tela', settings: { padding: 10, showHelpButton: true, lockScroll: true }, steps: [ { welcome: true, title: 'Bem-vindo!', content: 'Tour rápido desta tela...' }, { element: '[data-tour="painel-principal"]', title: 'Painel Principal', content: 'Descrição do recurso...', position: 'bottom' }, { element: '#btn-salvar', title: 'Salvar', content: 'Clique para gravar.', quadrant: 'top-right', split: 'h' } ] };
4
Instancie e registre

Exporte a instância e, se quiser, triggers para botões customizados.

minha-tela-tour-config.js
export const minhaTelaTour = new VanillaTour(config); TourRegistry.register('minha-tela', minhaTelaTour); export const { start: startMinhaTelaTour, bindTrigger: bindMinhaTelaTourTrigger } = createTourTrigger(minhaTelaTour);
5
Importe no template Django

Basta importar o módulo — o botão ? aparece e o usuário inicia o tour.

MinhaTela.html
{% block content %} <!-- conteúdo da página --> <script type="module"> import '../static/js/Tour/minha-tela-tour-config.js'; </script> {% endblock %}
6
Opcional — botão customizado

Vincule um botão da página para iniciar o tour sem usar o ?.

MinhaTela.html
<button type="button" id="btn-ver-tour">Ver tour</button> <script type="module"> import { bindMinhaTelaTourTrigger } from '../static/js/Tour/minha-tela-tour-config.js'; bindMinhaTelaTourTrigger('#btn-ver-tour'); </script>

Use quando a tela já tem um <script src="..."> clássico com funções globais (onclick, jQuery). Adicione o tour no final do arquivo com import() dinâmico — não é preciso converter o script inteiro para módulo ES.

1
Marque os elementos no HTML

Igual ao outro método: use data-tour ou seletores que já existam na página.

ConsultaListaOrcamento.html
<div id="consulta-orcamento" data-tour="filtros-orcamento"> ... </div> <button id="ConsultaListaOrcamento-consultar" onclick="ConsultaListaOrcamentos()"> Consultar </button>
2
Adicione o tour no final do JS existente

O caminho em import() é relativo ao arquivo JS, não ao HTML. Ajuste ../Tour/Tour.js conforme a pasta do seu script.

ConsultaListaOrcamento1-0-2.js
// ... funções existentes da página (mantidas como estão) ... // Tour — no final do arquivo import('../Tour/Tour.js').then(({ VanillaTour, TourRegistry, createTourTrigger }) => { const config = { helpButtonId: 'v-help-btn-orcamento', steps: [ { welcome: true, title: 'Consulta de Orçamentos', content: 'Tour rápido desta tela...' }, { element: '[data-tour="filtros-orcamento"]', title: 'Filtros', content: 'Refine a busca por data, status, placa...', position: 'bottom' }, { element: '#ConsultaListaOrcamento-consultar', title: 'Consultar', content: 'Clique para listar os orçamentos.', quadrant: 'top-right', split: 'h', allowInteraction: true } ] }; const tour = new VanillaTour(config); TourRegistry.register('orcamento', tour); // Opcional: expor para iniciar de outro ponto do mesmo arquivo window.startOrcamentoTour = createTourTrigger(tour).start; });
3
Mantenha o script clássico no template

Não altere para type="module" — funções como ConsultaListaOrcamentos() precisam continuar globais para onclick e scripts inline. Remova o import separado do *-tour-config.js se estiver fundindo tudo no mesmo arquivo.

ConsultaListaOrcamento.html
<!-- Script da página (inalterado) --> <script type="text/javascript" src="../../static/js/ConsultaListaOrcamento/ConsultaListaOrcamento1-0-2.js"></script> <!-- Não é necessário um segundo import do tour-config --> <!-- <script type="module"> import '...orcamento-tour-config.js'; </script> -->
4
Opcional — iniciar o tour programaticamente

De qualquer função do mesmo arquivo JS, após o import() resolver.

ConsultaListaOrcamento1-0-2.js
// Via função exposta no passo 2 window.startOrcamentoTour?.(); // Ou via TourRegistry (se registrou o tour) import('../Tour/Tour.js').then(({ TourRegistry }) => { TourRegistry.start('orcamento'); });
5
Opcional — botão customizado

Vincule o trigger dentro do callback do import(), ou use um <script type="module"> separado só para o botão.

ConsultaListaOrcamento1-0-2.js
import('../Tour/Tour.js').then(({ VanillaTour, createTourTrigger }) => { const tour = new VanillaTour(config); createTourTrigger(tour).bindTrigger('#btn-ver-tour'); });
6
Alternativa — converter o arquivo para módulo ES

Só use se puder expor explicitamente as funções usadas no HTML. Sem window.MinhaFuncao = ..., onclick e scripts inline quebram.

MeuScript.js + MinhaTela.html
import { VanillaTour } from '../Tour/Tour.js'; function MinhaFuncao() { /* ... */ } window.MinhaFuncao = MinhaFuncao; // obrigatório para onclick inline new VanillaTour({ helpButtonId: 'v-help-btn-minha-tela', steps: [ /* ... */ ] });

No HTML: <script type="module" src=".../MeuScript.js"></script>

Posicionamento — regra padrão

O posicionamento usa duas propriedades em conjunto: quadrant escolhe qual canto do elemento; split escolhe como o tooltip se ancora nesse canto.

1. Quadrant — as 4 zonas

O elemento alvo é dividido em um plano com origem no centro, formando quatro zonas:

top-left | top-right --------------+-------------- bottom-left | bottom-right

quadrant: 'top-right' significa: “use a zona superior direita do elemento como referência”.

2. Split — o eixo de corte (regra padrão)

Dentro de cada zona existem duas posições possíveis para o tooltip — total de 8 slots. O split define o eixo pelo qual o elemento é “cortado ao meio” para calcular onde o tooltip aparece:

split: 'v' (vertical) — padrão

Corte horizontal no meio da div. O tooltip vai acima ou abaixo, alinhado à metade esquerda ou direita da zona escolhida.

elemento
tooltip

Ponto âncora na metade horizontal da zona · borda superior ou inferior

split: 'h' (horizontal)

Corte vertical no meio da div. O tooltip vai à esquerda ou direita, alinhado à metade superior ou inferior da zona.

elemento
tooltip

Ponto âncora na metade vertical da zona · borda esquerda ou direita

Regra prática: se você só informar quadrant, o split é sempre 'v'. Para tooltip lateral (menu, botão à direita), adicione split: 'h' ou use o atalho quadrant: 'top-right-h'.

3. Combinações — os 8 slots

SintaxeSplitOnde o tooltip aparece
quadrant: 'top-right'vAcima, alinhado à metade direita
quadrant: 'top-left'vAcima, alinhado à metade esquerda
quadrant: 'bottom-right'vAbaixo, alinhado à metade direita
quadrant: 'bottom-left'vAbaixo, alinhado à metade esquerda
quadrant: 'top-right', split: 'h'hÀ direita, alinhado à metade superior
quadrant: 'top-left', split: 'h'hÀ esquerda, alinhado à metade superior
quadrant: 'bottom-right', split: 'h'hÀ direita, alinhado à metade inferior
quadrant: 'bottom-left', split: 'h'hÀ esquerda, alinhado à metade inferior

4. Quando usar cada split

  • split 'v' (padrão): cards, painéis, filtros largos — o tooltip não compete com o conteúdo lateral.
  • split 'h': itens de menu, botões na lateral, elementos estreitos — o tooltip abre ao lado sem cobrir o alvo.
  • Menus laterais: padrão do projeto é quadrant: 'top-right', split: 'h' (ver home-tour-config.js).

5. Modos alternativos

SintaxeComportamento
quadrant: 'top-right-h'Atalho para quadrant: 'top-right', split: 'h'
position: 'bottom'Legado — centralizado na largura total, abaixo do elemento (ignora quadrants)
position: 'top'Legado — centralizado na largura total, acima do elemento
welcome: trueModal central na tela, sem spotlight

6. Ajuste fino

{ element: '[data-tour="card"]', quadrant: 'bottom-right', split: 'v', // opcional — já é o padrão margin: 20, // distância entre tooltip e borda do elemento offsetX: -10, // deslocamento horizontal em px offsetY: 8 // deslocamento vertical em px }

Exemplos de customização

As customizações se dividem em dois níveis: globais (em config.settings, valem para todo o tour) e por passo (em cada item de config.steps). Experimente ao vivo na aba Customização.

1. Onde configurar

NívelOndeExemplos
Globalconfig.settingsCores, textos dos botões, padding do spotlight, lockScroll, defaults por zona
Por passoCada objeto em config.stepsPosição, margin, beforeShow, action, allowInteraction
Instânciaconfig.helpButtonIdID único do botão ? quando há mais de um tour na mesma página

2. Cores — paleta completa

Sobrescreva via settings.colors. Valores não informados usam TOUR_COLORS de Tour.js.

ChaveAplica emPadrão

footerRodapé do tooltip (Voltar / Próximo)#75c46a
overlayFundo escurecido da páginargba(0,0,0,0.7)
spotlightBorder / glowBorda e brilho do spotlightverde padrão
tooltipBg / tooltipShadowFundo e sombra do cardbranco / sombra suave
title / contentTítulo e texto do passo#111 / #444
navTextLinks Voltar, Próximo e Pular#262626
helpBtnBg / helpBtnIconBotão ? flutuanteverde / preto
arrowSeta que aponta para o elemento#ffffff
settings: { colors: { primary: '#75c46a', overlay: 'rgba(0, 0, 0, 0.75)', spotlightBorder: '#75c46a', footer: '#75c46a', title: '#111111', content: '#444444' } }

3. Textos e comportamento global

SettingPadrãoDescrição
padding10Espaço entre o spotlight e a borda do elemento alvo (px)
prevBtnText / nextBtnText / doneBtnTextVoltar / Próximo / FinalizarRótulos da navegação no tooltip
showHelpButtontrueExibe o botão ? ao carregar (não inicia o tour sozinho)
lockScrolltrueBloqueia scroll da página enquanto o tour está ativo
onLeaveMenu—Callback ao sair de um passo com isMenu: true (ex.: fechar menus)
settings: { padding: 12, prevBtnText: 'Anterior', nextBtnText: 'Continuar', doneBtnText: 'Concluir', showHelpButton: true, lockScroll: true }

4. Posição — margin e offset

margin é a distância entre o tooltip e a borda do elemento. offsetX / offsetY deslocam o tooltip em pixels após o cálculo da posição.

{ element: '[data-tour="card"]', quadrant: 'bottom-left', margin: 20, offsetX: -8, offsetY: 12 }

Para aplicar o mesmo ajuste em vários passos da mesma zona, use defaults em settings.quadrants:

settings: { quadrants: { 'top-left': { margin: 24, offsetY: 4, split: 'h' }, 'bottom-right': { margin: 18 } } }

Um passo pode sobrescrever o default da zona com margin, offsetX, offsetY ou quadrantOverrides no próprio objeto do passo.

5. Interação com o elemento alvo

Por padrão o overlay bloqueia cliques. Com allowInteraction: true, o usuário pode clicar no elemento destacado (útil para botões “Consultar”, links, etc.).

{ element: '#btn-consultar', title: 'Consultar', content: 'Clique aqui para executar a busca.', quadrant: 'top-right', split: 'h', allowInteraction: true }

6. Passo condicional — beforeShow

Função que retorna true para exibir o passo ou false para pular automaticamente. Ideal para resultados que só existem após uma ação.

{ element: '[data-tour="resultados"]', title: 'Lista de Resultados', content: 'Aparece após a consulta.', position: 'bottom', beforeShow: () => { const lista = document.querySelector('#lista'); return lista && lista.children.length > 0; } }

7. Menu lateral — isMenu + action

Abre o menu antes de posicionar o tooltip. Ao sair do passo (ou do tour), chama settings.onLeaveMenu para recolher os menus.

settings: { onLeaveMenu: () => collapseAllMenus() }, steps: [ { element: '[data-tour="menu-cadastros"]', title: 'Menu Cadastros', content: '...', quadrant: 'top-right', split: 'h', isMenu: true, scroll: false, animate: false, action: () => expandMenu('menu-cadastros') } ]

8. Modal e UI dinâmica — action + onExit

action roda ao entrar no passo (ex.: abrir modal). onExit roda ao sair (voltar, avançar ou encerrar). O motor aguarda o DOM estabilizar até actionMaxWait ms (padrão 200).

{ element: '#modalNotaFiscal .modal-dialog', title: 'Detalhes', content: 'Informações do orçamento selecionado.', position: 'bottom', actionMaxWait: 500, action: () => { $('#modalNotaFiscal').modal('show'); }, onExit: () => { $('#modalNotaFiscal').modal('hide'); } }

9. Scroll e animação por passo

PropriedadePadrãoUso
scrolltrueRola a página até o elemento antes de destacá-lo. Use false em menus fixos.
animatetrueAnima a transição do spotlight. Use false em passos de menu para evitar “pulo”.

10. Exemplo completo

const config = { helpButtonId: 'v-help-btn-minha-tela', settings: { padding: 10, lockScroll: true, colors: { primary: '#75c46a', overlay: 'rgba(0,0,0,0.75)' }, quadrants: { 'top-right': { margin: 20 } }, onLeaveMenu: () => { /* fechar menus */ } }, steps: [ { welcome: true, title: 'Bem-vindo', content: '...' }, { element: '[data-tour="filtros"]', title: 'Filtros', content: '...', position: 'bottom' }, { element: '#btn-acao', allowInteraction: true, quadrant: 'top-right', split: 'h', title: 'Ação', content: '...' } ] };

API

Referência do módulo Tour.js. O tour não inicia automaticamente — use start(), bindTrigger(), o botão ? ou TourRegistry.start().

1. Exports do módulo

ExportTipoDescrição
VanillaTourclassMotor do tour — instancie com new VanillaTour(config)
createTourTriggerfunctionRetorna { start, bindTrigger } para iniciar ou vincular cliques
TourRegistryobjectRegistro nomeado de tours: register, get, start
TOUR_COLORSobjectPaleta padrão (pode ser importada para referência)
TOUR_SLOTSstring[]Lista dos 8 slots de posicionamento (top-right, top-right-h, …)
import { VanillaTour, createTourTrigger, TourRegistry, TOUR_COLORS, TOUR_SLOTS } from './Tour.js';

2. Construtor — new VanillaTour(config)

CampoTipoDescrição
stepsarrayObrigatório. Lista de passos do tour.
settingsobjectOpções globais (cores, textos, padding, quadrants, callbacks).
helpButtonIdstringID do botão ?. Padrão: v-help-btn-{timestamp}.

Ao instanciar, o motor injeta estilos, cria overlay/spotlight/tooltip e, se showHelpButton for true, adiciona o botão ? ao body.

3. Métodos da instância — VanillaTour

MétodoDescrição
tour.start()Inicia o tour no primeiro passo (ou no primeiro passo não pulado por beforeShow).
tour.next()Avança para o próximo passo. No último passo, equivale a stop().
tour.prev()Volta ao passo anterior. No primeiro passo, não faz nada.
tour.stop()Encerra o tour, esconde UI, restaura scroll e executa onExit do passo atual se existir.
tour.destroy()Remove do DOM overlay, spotlight, tooltip, botão ? e todos os listeners. Use ao descartar a página/componente.

4. Teclado e acessibilidade

TeclaAção
→ (ArrowRight)Próximo passo
← (ArrowLeft)Passo anterior
EscEncerrar tour (stop())

O tooltip usa role="dialog" e aria-modal="true". O link “Pular Tutorial” também chama stop().

5. createTourTrigger(tour)

Helper para expor o tour a botões da página sem repetir lógica de clique.

const { start, bindTrigger } = createTourTrigger(homeTour); // Inicia diretamente start(); // Vincula um ou mais elementos (seletor, Element ou NodeList) bindTrigger('#btn-ver-tour'); bindTrigger(document.querySelector('.link-ajuda'));

Nos arquivos *-tour-config.js, o padrão é exportar funções nomeadas:

export const { start: startHomeTour, bindTrigger: bindHomeTourTrigger } = createTourTrigger(homeTour);

6. TourRegistry

Mapa global por nome — útil para menu de ajuda centralizado ou iniciar tour de outro módulo.

MétodoDescrição
TourRegistry.register(name, tour)Registra uma instância (ex.: 'home', 'orcamento').
TourRegistry.get(name)Retorna a instância ou undefined.
TourRegistry.start(name)Chama start() no tour registrado, se existir.
TourRegistry.register('home', homeTour); TourRegistry.start('home');

9. Fluxo de vida do tour

new VanillaTour(config) → cria DOM + botão ? │ ▼ tour.start() → passo 0: beforeShow? → action? → spotlight + tooltip │ ├─ next() / prev() → onExit do passo atual → próximo passo ├─ stop() / Esc → onExit → esconde UI → mostra botão ? └─ destroy() → remove tudo do DOM
